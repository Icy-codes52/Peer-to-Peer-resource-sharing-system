Peer-to-Peer Resource Sharing System
Project Statement
 

Problem statement

Students often need small stationery items such as a pen, a calculator, or a stapler at short notice, and buying them for one-time use is wasteful. At the same time, many students own spare items that sit unused. There is no simple way to see what is available among peers.

 

Scope

The project is a command-line application that maintains a shared list of stationery items. It covers adding items, lending items, and searching for items. It does not yet cover user accounts, return tracking, persistent storage, or a graphical interface.

 

Target users

Students in a college or hostel community who want to share stationery and other small resources with each other.

 

Features

• Shared item list with 20 pre-loaded items
• Add a new item to the list
• View available items and lend one out
• Search for an item's availability
• Simple numbered menu with an exit option
